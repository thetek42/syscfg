# twl

My personal Wayland window manager, based on dwl.

This software is based on:

- [dwl](https://codeberg.org/dwl/dwl)
- [dwl-patches/attachbottom](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/attachbottom)
- [dwl-patches/bar](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/bar)
- [dwl-patches/better-resize](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/better-resize)
- [dwl-patches/numlock-capslock](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/numlock-capslock/)
- [dwl-patches/unclutter](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/unclutter/)

The licenses can be found in the "licenses" directory.
